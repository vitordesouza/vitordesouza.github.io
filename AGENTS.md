# Repository instructions

Before working in this repository, read both `AGENTS.md` and `CLAUDE.md`. These instructions apply to Codex and every other agent, regardless of which instruction filename it loads by default.

`CLAUDE.md` contains the shared architecture and implementation guidance. For frontend design work, also read `design/HANDOFF.md` and inspect `design/Main.dc.html`; the handoff resolves differences between the canvas reference and the shipped site.
